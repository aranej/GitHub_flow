## 🔧 Setup & Installation

### Prerequisites
```bash
# Git (version control)
git --version  # Requires 2.30+

# GitHub CLI (automation)
gh --version   # Requires 2.0+

# Node.js (for some scripts)
node --version # Requires 16+

# jq (JSON processing)
jq --version   # Requires 1.6+
```

### Quick Setup
```bash
# 1. Clone this repository
git clone https://github.com/your-org/github-workflow.git
cd github-workflow

# 2. Install GitHub CLI
# macOS
brew install gh

# Windows
winget install --id GitHub.cli

# Linux
sudo apt install gh

# 3. Authenticate
gh auth login

# 4. Source automation scripts
source pr-automation-utils.sh
source issue-automation-utils.sh
source workflow-automation-utils.sh

# 5. Test
gh pr list
```
