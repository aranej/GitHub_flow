SETUP INSTRUCTIONS
================================================================================

1. INSTALL GITHUB CLI:
   macOS:
   $ brew install gh
   
   Ubuntu/Debian:
   $ sudo apt-get install gh
   
   Windows:
   $ choco install gh

2. AUTHENTICATE:
   $ gh auth login
   
   Choose: GitHub.com or GitHub Enterprise
   Recommended scopes: repo, workflow, admin:org_hook

3. VERIFY:
   $ gh auth status

4. USE UTILITIES:
   $ source pr-automation-utils.sh
   $ wait-for-checks 123 owner/repo
   
   OR
   
   $ ./scripts/daily-standup-report.sh owner/repo

5. SCHEDULE (Optional):
   Add to crontab:
   0 6 * * * ~/github-automation/scripts/daily-standup-report.sh owner/repo
   
   OR use GitHub Actions:
   See REAL_WORLD_EXAMPLES.md for workflow examples

SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

Q: Authentication fails?
A: Run 'gh auth login' and choose appropriate hostname
   Verify scopes with 'gh auth status'

Q: Rate limits exceeded?
A: Make sure you're authenticated ('gh auth login')
   Authenticated: 5,000 req/hour
   Unauthenticated: 60 req/hour

Q: Scripts not working?
A: Check GitHub CLI version: gh --version (minimum 2.0+)
   Enable debug mode: GH_DEBUG=api gh <command>
   Verify repository format: owner/repo (with slash)

Q: jq parsing errors?
A: Test jq syntax separately: echo '{}' | jq '.your.query'
   Use jq with --raw-output (-r) for strings
   Use --slurp (-s) for arrays

Q: Permission errors?
A: Check token scopes: gh auth status
   Add needed scopes: gh auth login --scopes repo,workflow
   Verify repo access: gh repo view owner/repo
